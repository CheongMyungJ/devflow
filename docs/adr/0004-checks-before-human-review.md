# ADR-0004: 검증은 사람 검토 전에, 승인은 버전을 명시해서

- 상태: Accepted
- 날짜: 2026-09-18

## 상황
원 요구사항은 "Step 완료 및 승인을 감지하여 Quality Gate 실행" 이었다. 이 순서에서는 빌드가 깨진 산출물을 사람이 먼저 읽게 될 수 있다.

## 결정
- Worker 완료 후 선언된 검증(deterministic → AI 리뷰)을 먼저 돌리고, 결과를 산출물과 함께 사람에게 제시한다. 자동 검증 실패 시 사람을 거치지 않고 재작업으로 보낼 수 있다.
- 공식 Gate 판정은 승인된 최종 버전에 대해 확정한다. 검증한 버전과 승인된 버전이 같으면 캐시된 결과를 쓴다.
- 승인 명령은 대상 Artifact 버전을 반드시 명시한다.
- 세션 안 대화에서의 동의는 승인이 아니다. 승인은 검토 명령으로만 한다.

## 이유
가장 비싼 자원은 사람의 주의력이다. 버전 명시 승인은 v1 을 보고 누른 승인이 v2 에 적용되는 사고를 막고, 서버화 이후 낙관적 잠금의 기반이 된다.

## 포기한 대안
- 승인 후에만 Gate 실행: 사람이 기계로 걸러질 결함을 읽게 된다.
